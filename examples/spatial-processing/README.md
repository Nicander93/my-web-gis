# 空间处理示例

示意数据，位于北京附近，不代表真实地块。

1. 通过“添加数据”分别导入 `input.geojson` 和 `masks.geojson`。
2. 打开“数据 → 空间处理”，选择 input 为输入 A，范围“全部要素”。
3. 面裁剪、面相交、面差集选 masks 为第二输入 B，范围“全部要素”。

| 工具 | 预期结果 |
| --- | --- |
| 面裁剪 | 2 个结果；只保留 A 的属性；重叠掩膜不产生额外重复记录 |
| 面相交 | 3 个结果；A_name、B_name 同时存在；仅边界接触的配对无面结果 |
| 面差集 | 2 个结果；两个区域均沿掩膜边界形成凹口 |
| 面融合，不分组 | 1 个结果，无原始属性 |
| 面融合，按 category 分组 | 1 个结果，category 为“同组”，不自动求和 value |

## 按位置提取

导入 `points.geojson`，选择“按位置提取”，输入为 points，第二输入为 masks，两层范围均选“全部要素”。

| 空间关系 | 预期结果 |
| --- | --- |
| 相交 | 2 个点：重叠范围内、合并范围边界；重叠范围内的点只输出一次 |
| 完全位于其中 | 1 个点：重叠范围内；边界点不输出 |
| 不相交 | 1 个点：范围外 |

提取保留完整几何与原属性，不把要素裁剪成局部。第二输入的多个面先合并，再判断整个要素的关系。位于孔洞内的点属于“不相交”，孔洞边界点属于“相交”。

完成后点击“查看结果”，打开属性表核对，再在检查器展开“处理来源”。保存项目并重开，结果和来源应保留。此文给出人工验证步骤，不表示人工验收已经完成。

## 区域统计与连接

1. 按区域统计：输入 masks，第二输入 points，两层范围均选全部；关系“相交”，数值字段 value，前缀 stats_。掩膜 A 的 count/sum/mean 为 2/30/15，掩膜 B 为 1/10/10。改为“完全位于区域内”后，二者均为 1/10/10。
2. 属性连接：再导入 lookup.geojson，输入上述统计结果，第二输入 lookup；两个连接键均选 name，带入 manager，保留全部输入，前缀 business_。两个区域分别获得对应负责人，几何与统计字段保留。
3. 空间连接：输入 points，第二输入 masks，关系相交，带入 name，左连接，前缀 region_。生成 4 条记录：内部点匹配 A/B 两条，边界点匹配 A 一条，外部点一条 region_name=null。改为内连接生成 3 条。
4. 每次生成结果后撤销，结果图层及其数据集应一起移除；重做恢复同一结果和来源。再保存重开并导出核对字段。项目重新打开后撤销历史不保留。
# 几何检查样例

导入 `invalid-geometries.geojson`，在“数据 → 空间处理 → 几何检查”选择全部要素。预期检查 3 个：1 个有效、2 个无效；问题为自交面和外环之外的孔洞。点击一条“选择并定位”返回地图查看该要素；全部选择包含两条问题要素。原数据、图层数量和撤销历史不应变化。可切换为选中范围再次检查。
