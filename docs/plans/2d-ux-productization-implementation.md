## 设计系统的代码构造

1. **语义 Token**：颜色、UI 字号、常规/图标控件高度、行高、Tab、状态栏、分组间距和窗口层级。紧凑密度默认 28px 控件/行，图标按钮 26px，字号 12px；标准密度通过同一组变量变更。
2. **组件适配**：Ant Design 消费 Token；共享 Button、窗口壳和字段布局负责焦点、禁用、提示、滚动与关闭规则。业务 Feature 不复制原型 CSS，也不另建通用组件框架。
3. **工作流组件**：右侧工具栏、逐层表格会话、计算器和样式参数围绕真实命令组合，状态目标明确；基础 UI 不依赖 OpenLayers。
4. **状态边界**：软件偏好→独立本机存储；窗口布局→Workspace/Docking；表格搜索/筛选→Session；识别结果→临时信息状态；数据/样式变化→Project + 既有 Command/Undo。关闭任务窗口只改变布局。
5. **验收约束**：hover/press 不改边框宽度、字体或几何；图标有名称/Tooltip；布局变化不使工程变脏；字号不改变地图符号/标注。
