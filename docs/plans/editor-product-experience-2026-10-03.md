# 编辑器产品体验改造

日期：2026-10-03。工作分支：`codex/feat-editor-product-experience`。

## 产品方向

编辑器以项目和场景对象为中心。二维地图与三维场景在创建项目时选择，项目打开后进入对应工作空间，顶部不再提供模式切换。三维工作空间保留模型、数据和水面的常用编辑入口，示例与环境配置不占据日常编辑主界面。

核心 Cesium 扩展包保持与桌面界面分离，本轮主要改变产品工作流和编辑器布局。

## 已实现

- 起始页、新建项目类型选择、项目名称、类型标识、未保存状态。
- `project.settings.workspaceType` 持久化；旧项目根据 `city` 推断类型；空三维项目和移除场景数据后仍保留显式类型。
- 新建与打开项目前的未保存保护；取消保存或保存失败时保留当前项目。关闭页面也有未保存保护。
- 三维专用数据、对象、编辑与视图菜单；导出入口导出场景，而非二维矢量数据。桌面使用原生保存窗口及文件写入服务；浏览器预览发起下载。
- 紧凑工具栏，突出添加资源；模型加载且可见时才启用变换工具；当前工具有选中状态。
- 可调整宽度、收起和恢复的对象与属性面板。对象列表提供显隐、选择、定位、搜索及加载状态。
- 添加资源独立弹窗，区分 3D Tiles、GLB 模型与 GeoJSON；示例仅放在空状态和帮助菜单。
- 对象属性与场景设置分开；变换提供中文轴名称和单位，使用明确的应用操作；弹窗字段、数据源与精确水面边界默认折叠。
- 模型变换直接进入手柄编辑；输入参数与拖动手柄均可撤销。GLB 从对象列表拖到地表时移动已有对象。
- 水面在视图中点击绘制边界，右键或 Enter 完成，Esc 取消；完成一次绘制只写入一次命令并自动选中对象。支持重新绘制边界和材质编辑。
- 资源失败显示可操作的中文提示，支持修改地址和重试；其他场景对象继续可用。
- 删除确认说明可撤销恢复。新弹窗支持语义标题、背景隔离、焦点约束、Esc 关闭和焦点恢复。
- 二维工具根据编辑能力、选择与历史状态禁用，并显示当前工具。

- Desktop TypeScript 类型检查通过。
- Desktop Vitest：22 个文件通过，111 项通过、5 项跳过；包含 4 项新项目类型持久化与兼容性测试及 3 项桌面场景导出保存、取消和失败测试。

- 浏览器实测：分别创建二维和三维项目；三维菜单不出现二维导出；取消新建保留未保存场景；新弹窗背景不可操作。
- 浏览器实测：拖动模型手柄产生变换，撤销恢复；输入平移并应用后撤销恢复。
- 浏览器实测：绘制四顶点水面，完成后自动选中；取消不产生绘制命令，撤销/重做恢复水面。
- 浏览器实测：缺失资源显示失败提示，修改为可用地址后恢复加载与模型工具。
- 1024 × 680 布局检查：无页面横向溢出，收起面板后视图占满工作区；检查后已恢复浏览器默认尺寸。

本轮验证使用浏览器生产预览，尚未验证 Tauri 原生文件选择、保存和应用重启后的实际打开流程。项目类型的序列化往返已由单元测试覆盖。
