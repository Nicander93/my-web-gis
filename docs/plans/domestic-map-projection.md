# 国内投影与地图视图闭环

基线：PR #47 合入后的 `1a779f0`。仅补二维产品路径，不扩大到跨引擎。

## 用户行为

状态栏的投影代码改成紧凑选择框，支持 4326、3857、4490、CGCS2000 3° 无带号 4534–4554 和带号 4513–4533。鼠标悬停可看名称及精度说明。图层编辑期间先结束编辑，再切换视图投影。

切换保持地理中心、旋转和局部米／像素比例；默认视图及已有缩放约束可能限制最终比例。原始矢量数据仍按 WGS84 保存，地图原生要素重投影，选择和表格保持。声明的视图范围同步变换，缩放上下限保留。切换可撤销，项目及场景文档保存投影；Popup 关闭，旧坐标读数清空。

3° 分带视图的应用显示范围限定为中央经线 ±1.5°、纬度 0–60°，用来生成有限视图和瓦片格网；不是 EPSG 完整适用区或精度声明。当前中心不在所选分带时拒绝切换，不把地图移到其他地区。4490↔4326 继续只是椭球近似，没有格网改正。坐标 CSV 明确按所选目标投影输出 X（东向）、Y（北向）；不会因切换地图而改写 GeoJSON 原始经纬度。

## 实现与来源

- vector-io 增加带号系列；假东距是带号 × 1000000 + 500000，中央经线是带号 × 3°，与无带号系列区分。
- Desktop 用相同 Proj4 定义注册 OpenLayers，设置有限视图范围，复用 SceneController 历史和文档投影；不引入第二套数据坐标。
- 参数核对使用 [Esri 官方投影坐标系表](https://developers.arcgis.com/rest/services-reference/enterprise/43b51ca910d5d49ba01f1d5cc720fd5a/pcs_pdf_11.5.pdf)，注册和有限投影范围依据 [OpenLayers 重投影文档](https://openlayers.org/doc/tutorials/raster-reprojection.html)。EPSG 官方站本次访问返回 403，未把其页面作为已读证据。
