# 工作区 UI/UX 整理

2026-09-30，按用户截图反馈处理。基于 `main@4311b46` 及当前工作区的启动修复；改动尚未提交。

## 问题与调整

- 面板重复标题及开发标签占用空间：每个面板保留一个标题，删除 PANEL/LEFT、INSPECTOR 等附加标签，标题栏缩为 36px。
- 搜索框常驻，操作栏挤占图层列表：搜索和新建组移到标题栏。搜索默认仅显示图标，点击展开并聚焦，关闭或 Esc 清空过滤、收起并恢复焦点。不另占一行常驻操作栏。
- “工作空间”伪根节点没有对应操作：删除该占位行，直接显示图层和真实分组。
- 排序/删除按钮常驻及无效选项入口：删除顶部上下移和无响应的图层选项。图层上下移放进现有右键/更多菜单；组的上下移、删除放进组右键/更多菜单。拖动排序保留。
- 原菜单用固定高度估计边界，而且位于带 backdrop-filter 的面板内：菜单通过 Portal 放到 body，按实际尺寸避让视口，长菜单可以滚动；支持方向键、Home/End、Esc、Tab 和点击外部关闭。
- 地图控件重复及面板遮挡：删除额外缩放控件，只保留 OL 缩放按钮，移到地图右上角。地图可见区域随左右/底部面板调整，比例尺、署名、坐标读数留在该区域内。
- 默认工具提示与比例尺挤在左下角：选择/平移不常驻提示，绘制/修改/删除提示放在比例尺上方。尚无指针数据时不显示假的 `1:0` 比例尺。
- 状态栏一直写“选择”及两处“就绪”：工具文本跟随实际命令；就绪状态不重复显示。
- 导入按钮灰字绿底与黑色默认焦点框：补齐反色文字和悬停颜色变量，统一键盘焦点样式。

## 验证范围

- Desktop test：17 个测试文件，89 通过、5 个可选 live 测试跳过。
- Desktop build：TypeScript/Vite 通过；既有较大产物和动态/静态导入混用警告仍在。
- 浏览器 1366×768：搜索自动聚焦、Esc 收起；组右键菜单出现，方向键切换焦点，Esc 关闭；底部属性表展开后地图底边与面板上边一致，缩放与比例尺仍在地图可见区域内。
- 浏览器 1920×1080：地图边界与左右面板边界一致，仅一套地图缩放控件，默认无搜索输入框；平移后状态栏显示平移。
- 导入按钮计算样式：文字 `rgb(255,255,255)`，背景 `rgb(88,107,93)`，未禁用。
