# 二维表格与地图键盘工作流

基线：PR #46 合入后的 `7101506`。本刀补齐二维已标示的键盘入口，保留输入内容自己的编辑行为。

## 用户行为

- 二维工作区的 Ctrl+Z／Ctrl+Shift+Z 对工程执行撤销／重做；表格记录行获得焦点时也可使用。
- 搜索框、单元格输入、其他表单、可编辑文本、菜单和弹窗不触发工程快捷键。Delete／Backspace 保持文字编辑行为，不绑定成删除要素。
- 记录行 Enter 定位保持现有路径。可编辑单元格 Enter 提交，Escape 取消；输入法组合输入的 Enter 不提交。
- 地图可以获得键盘焦点，Escape 取消未完成的绘制；已完成的数据保持不变。Popup 内 Escape 只关闭 Popup。
- 操作帮助与实际二维撤销／重做入口保持一致，不增加常驻说明。

## 实现与验收

Workspace 在处理快捷键前检查已消费事件、组合输入及焦点目标；复用 editCommands，不增加第二套历史。移除原先对所有 region 的 Escape 排除，防止地图获得焦点后无法取消绘制。单元格编辑器检查原生 isComposing。

- [x] 表内搜索及单元格输入的 Delete／Backspace／Ctrl+Z 不改变数据和工程历史。
- [x] 单元格组合输入不误提交；普通 Enter 提交，Escape 取消。
- [x] 记录行焦点下撤销、重做和 Enter 定位生效。
- [x] 聚焦地图后 Escape 清除已出现的绘制草稿，不增加数据。
- [x] Popup Escape 关闭与框选 Escape 回归通过。
