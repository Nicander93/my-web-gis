# 三维属性面板密度调整

参考用户提供的截图和已打开的 My3dtiles 0.9.46 属性管理器，采用名称与值同一行的属性布局，减少表单留白和常驻介绍段落。

- 属性输入与选择框高 24 CSS px，行高约 29 CSS px；数值使用等宽数字。
- 平移、旋转各占一行，保留完整的可访问名称与精确值。鼠标停留在输入框可查看完整数值。
- 说明移到 info 按钮：鼠标悬停、键盘聚焦或点击显示浮层；Esc 关闭。浮层显示在滚动区外，避免被面板裁切。
- 对象瓦片质量、场景画质与性能、光照、环境和底图采用折叠分组。抗锯齿、环境与底图默认收起；输入值在折叠时保留。
- 名称、分组、资源、材质、弹窗、顶点及批量属性使用同一密度；部分操作说明改为 info 提示。错误、空状态和待应用状态继续直接显示。
- 变换工具底部条仅显示当前工具、info 和结束编辑操作。
- CSS 限定在三维属性区，未调整二维属性表和全局对话框。

## 属性栏与自动生效

三维面板进一步合并为一条 30 CSS px 的“属性 / 对象 / 场景”栏，移除重复的对象名称标题与第二层标签栏；收起和调整宽度的功能保留。二维检查器仍使用默认标题栏。

场景的光照、阴影与辉光开关立即生效。雾浓度、UTC 时间、影像和地形地址在有效输入停顿 300ms 后生效，失焦或 Enter 立即确认，移除“应用场景设置”按钮。修改仅提交当前属性，保留其他设置；非法或未完成输入不写入场景，失焦时显示错误，Esc 恢复已应用值。

模型平移、旋转、缩放同样自动生效，移除“应用变换”按钮。输入框不会因每次提交而重建，保留编辑焦点；外部撤销/重做会同步已应用值。有效修改沿用项目命令和撤销历史。

原生复验：东向输入 24 自动应用，模型移动且输入框保持焦点；一次撤销恢复 0。太阳光照勾选后即时应用。环境分组保持展开，雾浓度 0.2 自动应用；输入 2 后失焦显示范围错误，一次撤销恢复有效原值 0，非法草稿未进入历史。未逐项复验真实影像/地形服务与时间控件完整录入流程。桌面构建和 144 个测试通过，5 个跳过。
