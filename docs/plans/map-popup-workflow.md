# 二维属性弹窗工作流

基线：PR #45 合入后的 `ea7dad5`。由当前任务承担产品取舍与验收。

## 用户行为

图层属性增加折叠的“属性弹窗”设置。勾选显示字段并选择标题字段，立即生效且可撤销；取消全部字段即关闭该图层弹窗。不增加常驻说明或新的大型面板。

选择／平移工具下点击要素显示紧凑弹窗，浏览不自动展开检查器。地图可选择开关只限制选择，不限制属性查看。关闭按钮、点击空白、隐藏图层、过滤排除要素、移除配置或进入几何编辑工具时关闭弹窗。

## 实现边界

- 通过现有 SceneController 事务写入 vector.interaction.popup，保持 selectable 配置和工程历史。
- React portal 管理内容，OpenLayers Overlay 管理地理位置与容器；窄视口自动平移以保留关闭按钮，卸载移除监听和 Overlay。弹窗内指针操作不进入地图手势，避免关闭后快速点击地图变成意外双击缩放。
- 拾取和已打开弹窗共同遵守运行时图层显隐及过滤条件，不从隐藏的选择高亮中弹出属性。
- 属性按文本渲染，不解释 HTML，不执行 URL；已有字段标签、数字和日期格式可显示。本刀不提供字段标签编辑或外链跳转。
- 字段候选优先使用数据集字段信息，并补充前 100 个要素中的属性键及已配置字段；不扫描全量大数据集。
- 不修改公共包协议，不扩大到三维或跨引擎。
