# 二维编辑捕捉

更新：2026-10-03。

原有绘制和修改工具已默认使用 OpenLayers Snap 捕捉当前图层，缺少用户设置入口。本次沿用该能力，新增工具栏磁铁开关和旁边的捕捉设置。

- 默认开启顶点和边线捕捉，范围为当前图层，容差为 10 个屏幕像素。
- 顶点和边线可分别启用，容差为 1～30 像素；二者都关闭时自动关闭捕捉。
- 参照范围可切换为全部可见矢量图层。按图层/组有效可见性、视图缩放范围和地图字段筛选后的实际要素参与捕捉。只读矢量可以作为参照，WMS/WMTS 图像不能。
- 绘制和修改时生效；地图操作提示显示“捕捉开启／关闭／已捕捉”。切换设置只更新 Snap，不替换 Draw/Modify，不丢弃绘制草稿。
- 新增、移除及几何变化更新目标；地图同步和视图变化刷新可见范围；停用工具时清理目标监听和反馈。
- 捕捉设置存放独立会话 Store，不写入 Project，不触发 Dirty 或 Undo/Redo；重新启动恢复默认值。
- 修改与删除仅允许命中当前图层，避免把参照图层的编辑写入当前 Dataset。

架构：Toolbar → 会话 Store → map-runtime-host → OlToolRuntime → OpenLayers Snap。UI 不直接管理地图交互，捕捉采用屏幕像素距离，不是地面米制距离。本次不包含交点捕捉、网格捕捉或三维编辑。
