# 二维地图可选择策略

基线：PR #44 合入后的 `e684ab4`。本次由当前任务承担产品取舍与验收，同时建立 [用户功能清单](../specs/user-capabilities.md)。

## 用户行为

图层属性增加单行“地图可选择”开关，默认开启、修改实时生效，可撤销。关闭只限制浏览时的地图点击与框选；已有选择不被清除，属性表仍可选择记录和双击定位。显式几何编辑目标是独立能力，此开关不代替图层编辑权限。

地图工具说明改为紧凑 `i` 提示入口，悬停查看，说明随开关更新；捕捉成功仍提供短状态反馈。不恢复大段常驻解释文字。

## 实现边界

- `layer.commands.ts` 通过现有 SceneController 事务修改 vector 的 interaction.selectable，保留 Popup 配置并接入统一历史。
- `OlMapRuntime` 从成功安装的文档更新原生图层的选择策略，失败准备保留原投影；拾取时不克隆含全部要素的完整文档。
- `OlSelectionRuntime` 对不可选择图层停止浏览选择手势，忽略地图选择请求；受控表格选择仍可以高亮。
- 不改公共选择包协议，不修改几何编辑捕捉，不增加跨引擎行为。Popup 的配置／显示闭环单独排期。
