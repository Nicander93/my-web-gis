# 二维与三维统一工作台

2026-10-08 二维工作流更新见 [工作台产品化重构](../design/workbench-productization.md)：二维改为地图／数据／编辑／分析／视图任务分类，检查器和属性表绑定独立目标，样式草稿切换需要确认，空间处理停靠右侧。本文件下方较早的二维分类和检查器跟随浏览规则由该更新替代；三维 Ribbon、紧凑属性与实时编辑规则继续保留。

本次约定更新 V0.1 中的工作台 UI 结构，也替代城市编辑器讨论稿中的五分类大图标 Ribbon。二维地图与三维场景仍是独立项目类型，保留 OpenLayers / Cesium 引擎和数据能力，不提供项目类型转换。

## 顶部

顶部采用紧凑两行 Ribbon。第一行放项目名称与下拉菜单、项目类型、添加数据、操作分类、撤销／重做／保存、更多、收起入口；三维额外提供预览。第二行是当前分类的小图标加文字工具和明确的编辑目标，不再增加品牌标题行或工具分组标题。

- 二维：编辑／地图。编辑包含选择、清除选择、绘制、修改、删除、捕捉；地图包含平移、缩放、全图、定位。
- 三维：编辑／场景。编辑包含选择、标绘、顶点编辑、模型变换、删除；场景包含视角、地表、光照、环境、水面。
- 折叠只隐藏第二行，切换分类重新展开。
- 更多承载面板开关、恢复布局、分组与空间处理等低频操作。
- 项目菜单承载新建、打开、保存；三维的场景整体导入／导出也在这里。

共用 `WorkbenchRibbon` 负责呈现，两套工作区提供自己的命令、禁用原因与状态。布局偏好只存入 Workspace，不进入项目序列化、脏状态或撤销历史。

## 图层与对象

右键和行尾常驻省略号打开同一菜单。二维菜单沿用已有图层能力判断，增加图层属性和“设为编辑目标”；样式、标注、属性表、过滤、导出、复制、重命名、移除都绑定明确图层。

三维菜单绑定当前对象或多选对象，提供适用的属性、样式、弹窗、数据源、刷新、定位、复制、锁定、重命名、删除、导出。对象导出生成可重新打开的场景文件，只包含所选对象及引用的分组和资源地址；不会打包远程模型文件。分组通过对象属性面板管理。

二维编辑目标是会话状态，与左侧浏览选择分开。第一次启动几何编辑固定当前可编辑本地图层，也可通过菜单显式设置。之后查看其他图层不会改变编辑目标。删除目标时退出几何工具；打开项目清除目标。服务影像和 WFS 快照不能设为几何编辑目标。

## 面板与选择

默认左侧打开，右侧和底部关闭。旧布局首次迁移也关闭右侧和底部，之后保留用户布局。左右面板共用容器和宽度偏好，画布为打开的面板让出空间。

点击图层或对象只选择，不打开右侧。显式属性／样式命令才打开右侧。已经打开的面板跟随当前选择，尽量保留检查栏目；新对象不支持当前栏目时退回基础属性。二维标明“图层属性”或“要素属性”，单个选中要素展示实际字段；字段编辑仍使用已有属性表。

三维预览隐藏第二行工具区和左右面板，退出后恢复原布局和 Ribbon 展开状态，预览不修改持久化面板尺寸或开关。

## 验证

执行依赖包构建、Desktop TypeScript／Vite 构建与 Desktop Vitest。回归用例覆盖编辑目标隔离、显式属性入口、服务能力限制、对象导出的引用完整性和项目不变性。

浏览器验收检查两种工作区：顶部只有一个 Ribbon；收起后切换分类重新展开；选择不自动开面板；显式属性打开并压缩画布；二维图层／要素标题准确；三维右键与省略号菜单、预览恢复和面板缩放。

原生 Tauri 文件对话框、操作系统凭据与真实远程服务需要桌面环境补充验收；本次不改变这些实现。
