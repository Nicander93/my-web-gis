# 二维与三维统一工作台

2026-10-13 的新基准见[产品功能与交互规范](product-interaction-spec.md)和[工作台原型](../prototypes/workbench/desktop-webgis-2d-final.html)。首批改动把 Shell 调整为文件、窗口、设置、帮助四项菜单，加上任务页签和工具三行；画布全铺底，窗口覆盖在上面，可以浮动或停靠；取消了常驻的恢复按钮。下文较早的布局规则保留作为历史参考，新实现以产品规范为准。功能阶段还没完成的项目要按实施记录区分，不能把原型上的按钮当成已经具备的运行时能力。

2026-10-08 的二维工作流更新：二维改为地图、数据、编辑、分析、视图几个任务分类，检查器和属性表绑定各自独立的目标，样式草稿切换需要确认，空间处理停靠在右侧。本文档下方较早的二维分类和“检查器跟随浏览”的规则，已被这次更新取代；三维 Ribbon、紧凑属性和实时编辑的规则继续保留。

这次约定更新了 V0.1 里的工作台 UI 结构，也取代了城市编辑器讨论稿中的五分类大图标 Ribbon。二维地图和三维场景仍然是两种独立的项目类型，各自保留 OpenLayers 和 Cesium 引擎与数据能力，不提供项目类型之间的转换。

## 顶部

顶部采用紧凑的两行 Ribbon。第一行放项目名称与下拉菜单、项目类型、添加数据、操作分类、撤销与重做与保存、更多、收起入口；三维还额外提供预览。第二行是当前分类下的小图标加文字工具，以及明确的编辑目标，不再增加品牌标题行或工具分组标题。

- 二维：编辑和地图。编辑包含选择、清除选择、绘制、修改、删除、捕捉；地图包含平移、缩放、全图、定位。
- 三维：编辑和场景。编辑包含选择、标绘、顶点编辑、模型变换、删除；场景包含视角、地表、光照、环境、水面。
- 折叠只隐藏第二行，切换分类时会重新展开。
- 更多里放面板开关、恢复布局、分组和空间处理等低频操作。
- 项目菜单放新建、打开、保存；三维的场景整体导入和导出也在这里。

两套工作区共用 `WorkbenchRibbon` 来呈现，各自提供自己的命令、不可用原因和状态。布局偏好只存进 Workspace，不进入项目序列化，也不影响未保存状态或撤销历史。

## 图层与对象

右键菜单和行尾常驻的省略号打开的是同一个菜单。二维的菜单沿用已有的图层能力判断，增加了图层属性和“设为编辑目标”；样式、标注、属性表、过滤、导出、复制、重命名、移除都绑定到明确的图层。

三维的菜单绑定当前对象或多选的对象，提供适用的属性、样式、弹窗、数据源、刷新、定位、复制、锁定、重命名、删除和导出。对象导出生成的是一个可以重新打开的场景文件，只包含所选对象及其引用的分组和资源地址，不会打包远程的模型文件。分组通过对象属性面板管理。

二维的编辑目标是会话状态，和左侧浏览时的选择分开。第一次开始几何编辑时，固定到当前可编辑的本地图层，也可以通过菜单显式设置。之后查看其它图层不会改变编辑目标。删除目标图层时退出几何工具，打开项目时清空目标。服务影像和 WFS 快照不能设为几何编辑的目标。

## 面板与选择

默认左侧打开，右侧和底部关闭。旧布局第一次迁移时也关闭右侧和底部，之后保留用户自己的布局。左右面板共用容器和宽度偏好，画布会为打开的面板让出空间。

点击图层或对象只是选择，不打开右侧面板。只有显式执行属性或样式命令才打开右侧。已经打开的面板会跟随当前选择，尽量保留当前的检查栏目；新对象不支持该栏目时退回基础属性。二维会标明是“图层属性”还是“要素属性”，单个选中的要素会展示实际字段；字段编辑仍然使用已有的属性表。

三维预览会隐藏第二行工具区以及左右面板，退出后恢复原来的布局和 Ribbon 展开状态。预览不会修改持久化的面板尺寸和开关。

## 验证

执行依赖包构建、Desktop 的 TypeScript 与 Vite 构建，以及 Desktop 的 Vitest。回归用例覆盖编辑目标的隔离、显式属性入口、服务能力限制、对象导出的引用完整性和项目不被改动。
