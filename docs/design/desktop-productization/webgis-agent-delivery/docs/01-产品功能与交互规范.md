# Desktop WebGIS 产品功能与交互规范

> 版本：Implementation Baseline 1.0 · 2026-10-13  
> 对应原型：`../prototypes/desktop-webgis-2d-final.html`、`desktop-webgis-3d-final.html`  
> 面向：产品、前端、GIS Runtime、测试 Agent  
> 状态：**已定基准，直接实施；范围变化须单独记录**

## 0. 决策优先级与用词

- **规范优先级**：本交付包的产品规范、UI/UX 规范与验收标准 > 两个最终 HTML 的交互/外观 > 2026-10-13 之前的讨论 > 项目内早期 PRD V0.1。原型中尚未实现的真实运算不构成可交付能力。
- **MUST**：本轮必须满足；**SHOULD**：尽可能交付，阻塞需书面解释；**LATER**：明确不在本轮。不得用展示性按钮、固定数值、动画模拟冒充实现。
- 本轮交付的软件由**二维项目**和**三维项目**组成。应用共享 Shell、窗口系统、命令与项目服务，**单个项目仅属于一种工作区类型**。不做同项目多视图、实时 2D/3D 联动、二三维自动转换。
- 使用专业但清晰的 GIS 术语。`GraphicLayer` 是可发布 Cesium API 和内部渲染容器，**不是用户必须创建的场景树节点**。

## 1. 主要对象及其关系

| 概念 | 用户语义 | 数据/行为 |
|---|---|---|
| Project | 一份 `.webgis.json` 工程 | type=`2d` 或 `3d`；保存业务内容，不保存本机窗口几何 |
| Folder | 场景树/图层树的普通文件夹 | 可多级嵌套；可混放各种可组织对象；拥有显隐、锁定状态，不继承样式 |
| 2D Data Layer | 面向数据集的图层 | 一对多 Features；字段、属性表、过滤、样式、编辑能力 |
| 3D Graphic | 独立标绘对象 | 每个 POI、文字、线、面有独立 ID、几何、样式、业务属性、交互配置 |
| 3D Asset Node | 一个 GLB / 3D Tiles / 影像等 | 引用外部资源；可单独显示/定位/配置 |
| 3D Tiles Effect | 属于指定 Tileset 的裁剪/压平配置 | 可启停、编辑、重排（适用时）、撤销和持久化；不修改原始瓦片 |
| Selection | 临时选择状态 | 不自动打开属性窗口，不因为属性表选中就自动定位 |

**禁止**把用户新建文件夹自动转换成 GraphicLayer，或要求“先建 GraphicLayer 再画 POI”。500 个独立 POI 仍为 500 个可管理对象；内部可用共享 Cesium `GraphicLayer`/`CustomDataSource` 渲染，不要求与对象一一对应。

## 2. 桌面工作流和公共交互

### 2.1 启动与项目

1. 启动界面：`新建二维地图` / `新建三维场景` / `打开项目` / `最近项目`。最近项目不可用时保留条目并显示问题。
2. 打开项目时根据保存的类型进入相应工作区；新建、打开、关闭或切换之前检查项目脏状态。
3. `Ctrl+S` 保存；`Ctrl+Shift+S` 另存为。写入失败不得清除 dirty。保存路径变更后需重新基准化相对资源路径。
4. 保存内容：数据源及其 CRS、图层/文件夹/对象、属性/样式/变换、二维地图状态或三维相机及效果、必要的数据编辑结果。外部凭据不写入项目。
5. `自动恢复草稿` 写入本机独立恢复缓存，不覆盖正式项目。发生修改后间隔保存（建议约 2 分钟，实施时可配置）；崩溃重开出现恢复/舍弃提示；正常成功保存后清理过期草稿。草稿有大小与保留期限制，支持写入原子性。
6. 原有文件、旧版 scene/schema 应支持迁移或明确报不支持；**不可默默删除未知节点**，也不可覆盖尚未加载完毕的项目。

### 2.2 统一工作区

- 顶部**一行应用菜单** `文件 / 窗口 / 设置 / 帮助`，**一行 Ribbon Tab**，**一行 Ribbon 工具**；底部状态栏。
- 二维 Ribbon：`地图 / 编辑 / 数据 / 分析`；三维 Ribbon：`场景 / 标绘 / 编辑 / 瓦片 / 分析`；具体命令因能力不同而不同。未支持的命令置为不可用并解释原因，禁止假执行。
- 地图/Cesium 视口在 Workspace **完整铺底**。停靠、浮动窗口覆盖而不收缩画布；双击定位仍落在整个视口的几何中心，不为了避让侧栏而偏移。
- `窗口`菜单可切换：树、检查器、属性表、工具箱、日志、性能与诊断等；关闭后完全消失，**不保留固定边缘恢复按钮**。可通过窗口菜单重新打开；支持保存布局与重置布局。
- 初始布局：左侧树打开；右侧检查器和底部属性表关闭；底部属性表打开时横跨**整个 Workspace**（包含左、右区域的下方）。
- 停靠/浮动窗口可拖动、调整尺寸、关闭；属性对话框允许非模态存在，关联到固定的对象 ID，不能因更换选择而切换其编辑目标。
- 本机记住窗口位置、尺寸、浮动/停靠、可见性；项目文件**不保存本机 Docking 布局**。

### 2.3 对象选择与右键

- 地图或树**单击选择**；`Ctrl` 切换多选、`Shift` 范围选择（树、表格遵守明确顺序）；不需要进入编辑模式才能选择。
- 树和地图**双击对象定位**；双击空白不触发对象定位。定位目标中心使用整个地图视口，不推开面板。
- 右键显示**因对象类型/上下文不同的菜单**：属性、定位、重命名、显示、锁定、移动、复制、删除、重新加载/重新定位资源、属性表（适用时）。仅展示当前对象确实支持的动作。
- 地图选择更新树选中态，但不强制展开文件夹或滚动树；提供显式`在树中定位`。
- 检查器若已打开则跟随当前选择，但**选择不自动打开检查器**；可固定到某个对象。
- Cesium 拾取 3D Tiles 子 Feature 时，检查器可显示该 Feature 元数据，树中仍保持 Tileset 图层选中；提供`返回图层`。不展开海量 Tileset 内部 Feature 到树。
- 多对象样式编辑只修改用户明确指定的字段，未编辑字段保持不变；所有批量修改为单次可撤销命令。

### 2.4 Esc、绘制与编辑

| 活动状态 | Esc | 提交方式 |
|---|---|---|
| 普通选择 | 关闭上下文菜单或取消暂态，不清空现有选择 | 单击选择 |
| 连续 POI/文字放置 | 退出工具；保留已经成功创建的对象 | 每次单击独立提交一个 Graphic |
| 正在绘制线/面 | 丢弃当前尚未完成的草稿并退出工具 | Enter 或绘制上下文的右键完成 |
| 拖动已有 POI | 取消本次拖动，恢复起点 | 单击新位置提交 |
| 拖动 Gizmo | 撤销正在进行的手势，退出当前编辑工具 | 松手生成一次编辑命令 |
| 属性窗口存在未应用值 | 遵循窗口取消规则，不能误提交 | Apply / OK / Cancel |

- Backspace 在绘制线/面时回退最后控制点；在文本输入焦点内必须作为正常编辑键，不执行 GIS 命令。
- Ctrl+Z / Ctrl+Y（或 Ctrl+Shift+Z）作用于已提交命令；单次绘制会话内的 Backspace 不应混入全局撤销栈。
- 工具切换要清理临时对象、控制柄、事件监听，并正确恢复相机/地图交互。

## 3. 二维工作区（OpenLayers）

### 3.1 图层、数据及 CRS

- 图层树自由文件夹多级嵌套、顺序与地图绘制顺序一致；支持显示/锁定、重命名、拖拽跨目录、搜索和批量操作。
- 加载本地 GeoJSON、Shapefile ZIP、CSV（字段映射）、DXF（坐标系/单位/子图层）；地图服务 WMS、WMTS、WFS。支持错误提示、重试和服务图层选择。
- 源 CRS 与显示 CRS 是不同字段。文件有明确 CRS 则读取；无法确定时要求输入，不通过经纬度数值猜测。CRS **赋值**（修订元数据）≠ **转换/重投影**（实际改坐标），必须用不同命令和明确提示。
- 地图投影切换不应暗改已保存数据集坐标。GIS 数据导入应完整记录源坐标和内部坐标约定，导出按用户指定 CRS。

### 3.2 选择与矢量编辑

- 点/线/面选择，高亮、Ctrl/Shift 多选；框选/按表达式筛选属于可扩展的专业选择能力。
- 进入可编辑图层后：绘制点、线、面；移动顶点、插入、删除顶点；修改几何、删除要素；编辑前检查锁定、类型、几何有效性。
- 线/面处理至少明确包含：分割、合并选中面、裁剪、缓冲区、差集、相交等。**合并面**属于修改原图层的编辑命令，涉及多个要素属性冲突时需显式处理；不能混同于生成新图层的“融合/Union”处理算法。
- 数据处理默认**生成新数据集/图层**；直接修改原数据须单独标明且纳入撤销与确认。所有空间处理需要参数验证、忙碌/取消、错误信息、进度和输出范围说明。禁止将静态 SVG 或模拟结果当作算法输出。

### 3.3 属性表和字段

- 一个可停靠/浮动/最大化的属性表窗口，多个数据集以 Tab 呈现。打开新图层新增 Tab；切换 Tab 不清空原有选择/筛选/排序。
- 支持字段排序、隐藏列、搜索、过滤全部/已选/过滤行、字段统计、单元格编辑、批量编辑、字段计算器、字段类型检查；大数据集考虑虚拟行渲染。
- 点击表格行选中并高亮地图，**不自动移动视图**；双击行头/非编辑单元区域定位；编辑模式下双击可编辑单元格进入单元格编辑，避免行为冲突；显式提供`跳转到选中`。
- 表内联字段计算器直接修改本数据集，整体为一条原子撤销命令；空间处理工具箱的字段计算可输出新数据集。两者共用可验证的表达式内核，但语义不同。
- 字段变更必须校验类型、空值约束、计算失败不产生半成品；属性表保持字段顺序、滚动、排序等每数据集会话状态。

## 4. 三维工作区（Cesium）

### 4.1 场景树与独立标绘

- 自由文件夹可多级嵌套，夹杂 3D Tiles、GLB、GeoJSON、标绘 Graphic、影像等节点。Folder 不承担样式继承。
- 一次创建的单个 POI/线/面都是一个独立 Graphic，拥有独立样式；Ribbon 只提供**创建工具的默认样式预设**，创建后复制为对象自己的数据，不追踪继承。
- 内部 `GraphicLayer` 可集中容纳许多 Graphic，不与场景树的一项一一对应。支持 500 个独立 POI 的搜索、多选、显示与批量属性处理。
- 场景树中 GLB、Tileset 可以双击定位；3D Tiles 内部 Feature 仅由拾取查看，不能误认为普通可自由移动的三维独立对象。

### 4.2 标绘种类及交互

| 级别 | 类型 | 功能要求 |
|---|---|---|
| MUST | 普通点、图标点、文字、折线、多边形、矩形、圆/椭圆 | 建立对象、独立属性和样式、编辑、保存恢复 |
| SHOULD | 图文标牌、曲线、自由线 | 丰富标注选项与控制点编辑 |
| SHOULD/后期 | 直箭头、双箭头、攻击箭头、墙体、走廊 | 要有真实几何和控制点逻辑；若延期记录原因 |
| LATER | 运动轨迹、动态时序对象、复杂雷达/军事标绘 | 不加入本轮必达条件 |

- 连续 POI：点击 Ribbon 工具即进入模式，预览跟随鼠标，单击直接创建并继续放置，不反复弹属性窗口；Esc 退出。
- 已有 POI 的“移动”使用鼠标跟随定位，而不是 Gizmo；默认选择可见表面拾取，必要时切换地形/椭球模式。预览阶段不会改写正式存储。
- GLB 用局部/世界方向 Gizmo 平移、旋转、缩放；Tileset 只做整体矩阵变换；操作完成形成单次可撤销记录。
- 贴地、绝对高程、拾取到的模型表面位置应区分；不能简单把地形贴地当成 3D Tiles 任意表面贴合。`heightReference` 与地理坐标 Z 的含义要区分。
- 图标和文字可以属于一个 Graphic；不要求拆成两个树节点。Billboard、Label 需支持有意义的 Cesium 专业参数（anchor、offset、scaleByDistance、distanceDisplayCondition、disableDepthTestDistance 等），清晰标注原生属性与软件扩展属性。

### 4.3 专业属性窗口

- 检查器：当前选择的常用参数，紧凑可编辑，允许固定；位置/经纬度/旋转只是一个折叠分类，不应占据主要篇幅。
- 完整属性：独立可移动/调整尺寸的非模态窗口，左侧分类导航、右侧专业表单、字段搜索、英文 API 别名、数值输入校验、默认值与单位、Apply/OK/Cancel。
- 专项分类：3D Tiles（资源、可见性、样式、质量/LOD、缓存、变换、裁剪压平、元数据/诊断）；GLB（显示、材质/动画〔适用时〕、变换、资源、属性）；Graphic（几何、图标/文字、距离条件、交互、业务属性）。
- 样式即时预览可取消还原；数值/Gizmo 与表单不需要在同一瞬间双向实时联动，但**提交后数据必须一致**。

### 4.4 3D Tiles 裁剪与压平

- 裁剪、压平是绑定到目标 Tileset 的**场景效果**；支持：新建范围、多边形顶点编辑、参数窗口、实时预览、应用、撤销、开关、删除、项目持久化和重开恢复。不改写原始瓦片文件。
- 裁剪：优先 Cesium 原生 `ClippingPolygonCollection` / 需要时 `ClippingPlaneCollection`，明确保留内部/外部语义；校验 WebGL 能力以及 Cesium 版本和 Tileset 适配性。
- 压平：利用 `Nicander93/cesium-demo` 中局部 ENU + Canvas Mask + CustomShader 的实验思路，**禁止直接搬用写死高程、未对齐坐标系和无纹理上限的代码**。目标高程必须可设置，坐标空间正确且处理模型变换、多区域与 Shader 互斥/合成。
- 首轮验收至少用两套不同空间变换的实际 Tileset，在相机运动、LOD 切换、开关效果、保存恢复后验证；测试无法通过时不得标记为已完成。

### 4.5 测量与空间分析

- MUST：三维空间距离、贴地距离、面积、高度差等基本测量；临时结果不自动落项目。用户选择`保留测量`才生成独立管理对象。
- SHOULD：基础通视与剖面。通视给出视线采样与可见结论及精度边界，剖面显示图表与采样点。可视域属于后续专项，不允许仅画一个扇形冒充真实遮挡分析。
- 复杂工具采用**非模态浮动参数/结果窗口**，地图视口不缩小；工具取消恢复场景，应用可撤销。

## 5. 数据资源与持久化

1. 统一`添加数据`窗口：本地文件、本地目录、在线服务。二三维共用入口框架，各格式按需配置；支持拖拽添加，识别失败才让用户选格式。
2. 大型本地 3D Tiles / GLB 默认**引用**而非复制，项目保存资源 URL/绝对路径/相对路径。项目目录内资源优先写相对路径；另存为重算，不能原样复制相对路径字符串。
3. 本轮不做自动项目打包、外部文件批量复制、依赖收集 ZIP；现存“场景资源包”若属于旧功能可保留兼容入口，但不得作为新工作流主路径或本轮必达目标。
4. 本地源不存在时保留树节点和原属性，提示`重新定位数据源`；允许重新定位父目录批量修复同一来源下多个资源。错误可重试，不删除项目对象。
5. `重新加载`只在用户明确触发时刷新外部文件；有未保存矢量编辑时应阻止静默覆盖或要求明确选择。服务刷新不把密钥写入项目日志。
6. **保存项目默认不覆盖外部数据源**。需由明确的导出/写回操作执行；输入源不可写或格式不支持时不提供写回选项。

## 6. 诊断与反馈

- `窗口 → 性能与诊断`：性能 / 资源 / 调试三个 Tab，默认关闭；支持浮动/停靠。
- 性能：FPS、帧耗时、可获取的内存；OpenLayers 静止按需渲染显示`空闲`，不得将 `0 FPS` 视为性能故障。
- 资源：Cesium 已加载/可见瓦片数、请求错误、层数、相机高度；OpenLayers 图层/要素/瓦片请求/CRS/分辨率。指标因环境不能获取时标注`不可用`、`估算`。
- 调试：适用时显示瓦片包围盒、LOD、加载错误、2D 边界/网格等；资源负担大的诊断默认关闭。仅在启用时采样，关闭后停止额外性能工作。
- `窗口 → 任务日志`独立于实时诊断，记录异步导入、处理、刷新与错误，支持取消、定位错误、重试。

## 7. 明确不做

本轮不实现：同一项目内同时包含多个二维/三维视图、二三维自动联动、真实数据的项目打包复制、大型目录全量文件监听、外部数据未经确认自动写回、完整历史版本管理、多人协作、3D Tiles 源文件网格重建、全量高级地形模拟。**对没有实现的专业工具不提供误导性的“运行成功”状态。**
