# Desktop WebGIS UI/UX 设计与组件规范

> 版本：Implementation Baseline 1.0 · 2026-10-13  
> 唯一最终视觉参考：`../prototypes/desktop-webgis-2d-final.html` 和 `desktop-webgis-3d-final.html`  
> 适用：React + Tauri 桌面端；覆盖独立二维、三维项目

## 1. 产品观感与信息密度

定位为成熟桌面 GIS 工具，参考 QGIS 的专业信息组织、窗口管理以及 GIS 工具操作逻辑。要求：**安静、紧凑、内容优先、必要时专业信息密集**。不能把所有属性、所有工具、所有状态卡片同时铺在界面上；不能将生产工具做成营销 Dashboard。

- 浅色中性背景，克制的绿色强调色。少量手绘/拟人风用于 Logo、空状态和插图；**工具图标与参数表单必须规整精准**。
- 业务状态层次：应用框架 < 用户当前操作 < 地图/数据；地图永远是最大的工作区域。
- 预设颜色参考**两份 HTML 中的 CSS 变量**，不要另行发明第二套视觉主题。示例：3D 以 `--paper:#fafbf9`、`--line:#dfe4e2`、`--accent:#2f695b`，2D 以 `--bg:#f7f9f6`、`--green:#346e55` 为近似基准；实现时将同义色收敛为一套 Design Token。
- 中文优先、英文 API 名字可搜索；优先系统字体和稳定的 UI 字体回退，不对所有用户强制安装定制字体。数字、坐标、单位在输入/表格中等宽对齐。

## 2. 原型与代码实现的边界

HTML 中内嵌 SVG 地图、演示 POI、模拟数据和弹窗只用于**UI 结构/交互样例**。正式实现必须复用真实 OpenLayers / Cesium Renderer、项目命令与文件服务。Agent 不能照搬模拟 `toast('成功')` 代替真实操作。

优先复现：空间布局、窗口层级、工具密度、面板操作、属性区块、状态反馈和快捷键语义。示意地图配色和演示图层名称不属于真实数据要求。

## 3. 统一结构

```text
Desktop App
├── Application Menu (1 row): 文件 / 窗口 / 设置 / 帮助
├── Ribbon Tabs (1 row): 按项目类型切换
├── Ribbon Tools (1 row): 紧凑图标 / 工具组 / 下拉
├── Workspace Overlay Root (full bounds)
│   ├── GIS Canvas (absolute, full width & height)
│   ├── Docking Windows (left/right/bottom/floating)
│   ├── Context Menus / Tool Hints / Nonmodal Editors
│   └── Temporary drawing handles / measurement overlays
└── Status Bar
```

**非协商布局规则：**

1. **画布占据 Workspace 整个范围**，不得给左/右面板预留真实空白宽度；GIS 鼠标坐标仍以原始 Canvas 实际尺寸解析。
2. 左右面板默认覆盖在画布上；浮动窗口可移动和尺寸调整；操作窗口打开时不应触发地图 resize 或相机 reframe。地图被窗口覆盖是允许的。
3. `flyTo` / 定位的目标点在**完整视口几何中心**。禁止依据面板边界人为加偏移。
4. 属性表底部停靠时横跨 Workspace 100% 宽；可浮动/最大化。左/右面板及底部可互相遮挡时，明确层级和焦点优先级，确保可以拖动/关闭，不隐藏关键控件。
5. 默认只开左树；右检查器、底部属性表、工具箱、日志、性能诊断都关闭；不保留边缘常驻恢复条或隐藏胶囊按钮。通过`窗口`菜单按需打开。
6. 顶部应用菜单、Ribbon Tab、Ribbon 工具严格三行，不叠加第四行“命令导航”或永久指令横幅。
7. 焦点模式只关闭浮层，不销毁状态；退出后原样恢复布局。布局保存在本机，跨项目不破坏用户习惯。

## 4. Window Manager 行为契约

| 能力 | 行为/约束 |
|---|---|
| 打开/关闭 | `窗口`菜单使用勾选态；关闭完全从可交互区域消失，再次打开恢复合理位置 |
| 停靠 | 左、右、底；不在不可访问的屏幕外部；支持从浮动变停靠、从停靠变浮动 |
| 浮动 | 有完整标题栏、可拖动、尺寸调整、关闭；始终高于地图而不必模态遮罩 |
| Z 顺序 | 单击或拖动激活窗口后置前；不同浮动窗口焦点明确，Esc 发给当前活动工具/窗口 |
| 定位持久化 | 独立于项目，通过布局服务管理；改变屏幕分辨率后位置 clamp 到可见范围 |
| 属性窗口 | 与对象 ID 固定绑定；场景选择变化不偷换编辑对象；支持 Apply/OK/Cancel |
| 模态限制 | 文件覆盖/严重验证等需确认的事务操作允许模态；一般属性、分析、裁剪参数优先非模态 |
| 无障碍 | 菜单和窗体键盘可到达；拖动之外提供关闭/停靠菜单；正确 focus trap 仅用于真正模态弹窗 |

可选实现技术：优先选择成熟且能满足上述行为的 Docking 库（需验证 React 19、布局保存/恢复、窗口叠层及许可）；不为追求第三方库而妥协“地图不缩放”约束。通用窗口可用成熟 React 控件，复杂 GIS 图形控件自行实现。

## 5. Ribbon 和工具状态

- 2D Tabs：**地图 / 编辑 / 数据 / 分析**。
- 3D Tabs：**场景 / 标绘 / 编辑 / 瓦片 / 分析**。
- Tab 下为单行工具组，主操作一眼可见，低频工具放 Dropdown/更多。图标统一使用 Lucide 或同级别单线图标，标签短且明确。
- 一个工具可处于：`available`、`disabled(reason)`、`active`、`busy(progress)`、`error`。点击 disabled 需展示可理解原因，不能静默失败。
- 有上下文的操作例如`压平`仅在选中可编辑 Tileset 时启用；`移动轴`仅模型/目标 Tileset；`编辑顶点`仅适用 Graphic/矢量。
- Ribbon 的取消/选择工具始终可访问；Esc 行为见产品规范；绘制过程只用紧凑工具提示而不是塞满全屏的操作教学。
- 不在生产 Ribbon 里展示没有运行时实现的“模拟裁剪/运行分析”按钮；如果产品路线需要保留未上线入口，明确标记为不可用。

## 6. 场景树、图层树和右键菜单

树节点紧凑展示：显隐眼睛、展开状态、图标、名称、加载错误/锁定信息、右键更多。文件夹和对象可混排，无系统强制的点/线/面分类。

- 文件夹多级嵌套、任意节点拖放、跨父目录移动、排序。拖放目标高亮；非法拖放有明确反馈；禁止循环父子关系。
- 单击选择，不强制滚动；双击定位；右键菜单具备操作能力检查，显示完整属性入口。
- 节点显示隐藏是独立状态；父文件夹可见/锁定参与**有效状态**计算，不改写子对象自己的显隐/锁定值。
- 搜索时可看到命中的深层对象及父路径，允许`在树中定位`，搜索结束保留用户原先的展开状态。
- 树大于数百项时引入虚拟列表、增量渲染/按需展开。独立 POI 不需要转换为数据图层。
- Tileset Feature 元数据使用检查器拾取视图，不能创建百万个树节点。

## 7. 检查器与完整属性窗口

**检查器** = 当前选择快速编辑，已开才响应选择变化，可固定对象；选择空白时展示简洁空态。非当前对象类型的字段不能占位。

**完整属性** = 独立窗口。推荐 2 列：左侧分类导航（可搜索）、右侧密集专业表单；主动作区底部 `应用 / 确定 / 取消`。固定对象 ID、dirty 草稿、输入验证、效果实时预览与取消回滚。

### 7.1 分类建议

| 对象 | 属性分类 |
|---|---|
| 二维矢量图层 | 常规、源与 CRS、符号化、标注、字段、过滤、渲染、元数据 |
| 二维要素 | 常规、业务字段、几何、编辑历史/辅助信息 |
| 3D Tiles | 常规、资源、显示与样式、LOD/缓存、裁剪与压平、位置/变换、拾取元数据、诊断 |
| GLB | 常规、资源、显示/材质、动画（有时）、变换、交互、元数据 |
| POI / 图标点 | 常规、图标、文字、距离与可见条件、交互/弹窗、位置、业务属性 |
| 线/面 Graphic | 常规、线型/材质、面填充/轮廓、几何点、高度模式、交互、业务属性 |
| Folder | 名称、可见/锁定、组织信息；**没有图层样式编辑** |

Cesium 原生字段（如 `maximumScreenSpaceError`、`scaleByDistance`、`heightReference`、`distanceDisplayCondition`）保留英文 alias 搜索；显示中文可读名、范围单位、警告/帮助；软件自定义扩展另行标识。

### 7.2 表单规则

- 严格区别设置的草稿值、预览值、已应用值。`Apply` 可连续提交且保留窗口，`OK` 提交后关闭，`Cancel` 回滚**未应用**的更改。
- 数值单位、默认值、边界条件和精度明确，不可输入 NaN/Infinity；颜色/符号/可见性实时预览需有回滚。
- 切换树选中对象后，不改变已打开属性窗口所编辑的目标。
- 位置、经纬度、旋转和缩放集中于一个专业分类，不占所有属性页面的主要空间。Gizmo 数值编辑交替使用，无需在输入拖拽同时每帧同步，但结果一致。

## 8. 属性表、工具箱、参数窗

### 属性表

- 底部整宽一个 Tab 容器，支持多个数据集，打开/关闭/浮动/最大化。
- 上方只放紧凑工具栏：筛选、搜索、只看选中、统计、编辑开关、更多字段操作。
- 可读/可编辑状态明显区分。输入合法性、类型转换、批量应用/撤销与执行进度明确。
- 行选中只高亮地图，不自动缩放；行头双击定位；编辑单元格双击进入编辑（可编辑模式）。
- 大量记录使用虚拟滚动/分页策略，保留每 Tab 滚动、列宽、筛选和排序状态。

### 工具箱及结果

- 工具箱可搜索，有类别、参数概要及运行入口；处理算法弹出非模态任务窗，展示参数、CRS/单位、输出策略、进度/取消、错误与产物。
- 剖面等多数据点结果可使用可调整尺寸的图表窗口，结果和来源清楚。

### 裁剪/压平

- 流程：选择 Tileset → Ribbon 工具 → 绘制/指定范围 → 参数窗 → 预览 → 应用。
- 参数窗应显示目标对象名称、保留内部/外部或目标高程、范围编辑、启用状态；未完成时 Esc 取消。
- 重开项目后配置列表可见；选中目标 Tileset 可在其完整属性的`裁剪与压平`页统一管理。

## 9. 统一反馈与状态栏

- 状态栏统一高度/视觉样式。二维显示 CRS、比例尺/分辨率、坐标、选中数量；三维显示坐标、相机高度/方向（适用时）、选中数量、渲染状态；都显示 dirty、后台任务/错误入口。
- 命令完成反馈须可核对：新建图层节点或结果集、实际修改画面、可撤销记录，不能只冒一个 toast。
- 异步操作有 `loading / success / error / cancel` 生命周期；网络错误和资源丢失可追溯到具体图层/数据源。
- 诊断独立窗口三 Tab（性能/资源/调试）；OpenLayers 静态帧率显示空闲；内存/显存未知显示“不可用”，估算值标注“估算”。

## 10. 尺寸、布局与视觉验收

下面是实施建议的初始范围，**原型实际效果优先**，数字可以根据真实 UI 密度做小幅调整：

| 组件 | 建议 |
|---|---|
| 应用菜单行 | 32–38 px |
| Ribbon Tabs | 30–36 px |
| Ribbon 工具行 | 48–68 px（紧凑一行） |
| 状态栏 | 24–30 px |
| 左树首次宽度 | ~260 px |
| 检查器默认宽度 | ~310 px，默认关闭 |
| 属性表初始高度 | ~280–320 px，默认关闭 |
| 工具控件 | 30–34 px 高，密集表单可更小但应满足可点击区域 |

验收至少使用：**1366×768**、**1920×1080** 两种窗口尺寸，并分别检查 100%、125% Windows 缩放下的主布局；浮窗不能越过可访问屏幕边界。对最终原型执行结构比对，而不是只通过截图对比色值。

## 11. UI 自动化用例（必测）

1. 新建 2D：左树开，其他关；打开属性表，验证横跨 Workspace；地图底图有效视口不改变。
2. 二维图层右键“属性”→浮动窗口，修改样式 Apply → 图层改变；Cancel 未应用草稿不改变。
3. 图层树选中 → 属性表行单击 → 只高亮地图；双击行头才定位。
4. 调整/拖动/关闭左右和底部窗口，重启后布局仍在；重置布局恢复左树开、右下关。
5. 新建 3D → 图标点 → 连续点击生成三个独立 Graphic → Esc 退出 → 再点击不新增对象。
6. 选中独立 POI → 右键属性；修改图标/大小，仅更新当前对象，不修改相邻 POI。
7. 3D Tiles 裁剪 → 未应用 Esc 后不留临时控制柄、不改变既有效果。
8. 同时打开性能诊断和属性浮窗、拖动其中一个，不改变 Cesium viewer 画布尺寸或目标定位中心。
9. 键盘聚焦到数值输入/属性表单元格后按方向键和 Backspace，不触发地图工具快捷键。
10. 布局在小屏打开时所有窗口标题栏/关闭操作仍可达。

## 12. 反模式（设计禁区）

- 将生产软件做成大型按钮卡片、全屏 Dashboard、常驻帮助提示或“工具展示墙”。
- 通过在地图旁边减宽生成所谓 Docking；或为了避让面板修改定位点中心。
- 把属性检查器做成只有 4 个概览字段的 Demo；把全部专业字段同时无分类地摊开。
- 给每个 POI 自动创建树中 GraphicLayer，或使用强制点/线/面分类文件夹。
- 截断复杂字段、隐藏保存失败、假进度、假测量结果、假压平截图。
- 强制覆盖用户自己的窗口布局，或在更换项目后失去焦点/面板浮动状态。
